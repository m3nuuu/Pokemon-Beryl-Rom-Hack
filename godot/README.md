# Pokémon Beryl (Godot)

The new home of Pokémon Beryl: a 2D game in Godot 4 with painted maps (no tiles), a Diamond/Pearl to
Black/White look and classic turn-based battles. Private, for friends only.

The ROM hack in the rest of this repository is no longer developed. The story, Pokémon and region
data still come from the design files (`beryl-design/*.ts`).

## Play

- **Without installing anything:** run the exported `PokemonBeryl.exe` (Windows).
- **From the project:** install [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/)
  (the standard version, not .NET), open `godot/project.godot` and press F5.

| Key | Button |
|---|---|
| Arrows / WASD | move (a quick tap turns on the spot) |
| Z / Enter / Space / E | A: talk, read, confirm |
| X / Shift / Backspace / Q | B: back, hold to run |
| Esc / C | party (menu placeholder) |
| F3 | show the grid and what every cell does |
| F11 | fullscreen |

A gamepad works too.

## What is in this first version

- 320 × 180 screen, scaled to whole pixels, single screen (battle and menus share it).
- Painted maps: `ground.png`, `overlay.png` drawn over the player, a colour key for walls, grass,
  water and ledges, and `map.json` for doors, people, signs, encounters and connections.
- Seamless walking between connected maps (Test Town to Route 1).
- Step-by-step grid movement, running, ledge jumps, NPCs that wander and talk, signs, doors and rooms.
- Wild encounters in tall grass and a classic battle: moves with type matchups, STAB, critical hits,
  stat stages, status (paralysis, burn, poison, sleep), Poké Balls, Potions, switching, EXP and
  level ups with new moves.
- The 32 species from the Pokédex doc with Manuel's sprites, and 95 moves.

All map art is placeholder, generated by `tools/make_placeholder_art.py`, until Manuel's drawings come in.

## Layout

```
godot/
  project.godot, export_presets.cfg
  scenes/main.tscn          the only scene; everything else is built in code
  scripts/
    autoload/data.gd        species, moves, type chart, items
    autoload/game.gd        party, bag, flags, controls
    overworld/              map loading, player, NPCs, warps, encounters, F3 debug view
    battle/                 Mon (one Pokémon) and the battle screen
    ui/                     text box and fonts
    tools/demo.gd           scripted play-through that takes screenshots
  maps/<id>/                ground.png, overlay.png, gameplay.png, map.json
  assets/                   characters, Pokémon sprites, battle backgrounds, fonts
  data/                     species.json (generated), moves.json (generated)
  tools/                    Python and Node helpers (see below)
  docs/DRAWING_GUIDE.md     how to draw maps and sprites for the game
```

## Tools

| Command | What it does |
|---|---|
| `python3 godot/tools/new_map.py <id> ground.png [overlay.png]` | starts a map folder from a painting |
| `python3 godot/tools/preview_map.py <id> [out.png]` | the picture with grid, colour key and events, to check a map |
| `node godot/tools/convert_design_data.mjs <beryl-design folder>` | species.ts to data/species.json |
| `python3 godot/tools/moves_table.py` | writes data/moves.json from the table in the script |
| `python3 godot/tools/make_placeholder_art.py` | regenerates the placeholder maps and characters |
| `godot --path godot -- --demo --shots=<folder>` | plays a scripted run and saves screenshots |

## Building

Install the Godot 4.3 export templates (Editor → Manage Export Templates), then
`godot --headless --path godot --export-release Windows build/windows/PokemonBeryl.exe`.
